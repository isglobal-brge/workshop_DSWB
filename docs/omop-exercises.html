How to use this sheet

Everything you need you already did once in the tutorial. Each exercise has a blank code block (# YOUR CODE HERE) and a collapsed hint — try it yourself first. Write your answers to the questions in plain words. We stay on the MIMIC dataset throughout.

ImportantReminders
  • Connect with profile = "omop".
  • Pooled summaries: pass scope = "pooled" and read the $pooled slot.
  • Check the output after every step.

Exercise 4 — Build your own recipe

Build a person-level table D with four columns: sex, age, the mean systolic blood pressure, and a binary flag for hyperlipidemia (the concept from Exercise 3). Preview it, execute it, then check the columns, dimensions and a summary.

# YOUR CODE HERE
TipHint 
rec <- omop_recipe(
  variables = list(
    omop_variable(table = "person", column = "gender_concept_id", format = "sex_mf", name = "sex"),
    omop_variable_age(name = "age"),
    omop_variable(table = "measurement", concept_id = 21492239, format = "mean", name = "systolic_bp"),
    omop_variable(table = "condition_occurrence", concept_id = 432867, format = "binary", name = "hyperlipidemia")),
  outputs = omop_output(name = "study", type = "wide"))
recipe_preview(rec, symbol = "omop", conns = conns)
recipe_execute(rec, out = c(study = "D"), symbol = "omop", conns = conns)
ds.colnames("D", datasources = conns); ds.dim("D", datasources = conns)

Exercise 5 — Filter at extraction

Re-extract, but this time keep only the older patients (age ≥ 60) as D_old, by adding a filter to the recipe. Then check the age range to confirm the filter worked.

# YOUR CODE HERE

Question: How many patients remain, and what is the new minimum age?

TipHint

Add filters = list(older = omop_filter_age(min = 60)) to your omop_recipe(...) and execute into D_old, then ds.dim("D_old", ...) and ds.summary("D_old$age", ...)[[1]]. Filtering during extraction means the servers only ever build the rows you asked for.
