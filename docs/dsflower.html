Federated machine learning with dsFlower

Three algorithms across three hospitals — no patient data ever leaves a site

Download the R script (.R) Source (.Rmd)

Welcome

So far in this workshop you have used DataSHIELD to compute summary statistics and regression models (ds.glm) across federated sites. This tutorial goes one step further: it trains machine-learning models with Flower — the popular federated-learning framework — underneath DataSHIELD, using the dsFlower package.

We will train three different algorithms and see where each shines:

  1. Logistic regression — a simple linear classifier,
  2. a neural network (PyTorch), and
  3. gradient boosting (XGBoost),

on two datasets: a breast-cancer cohort (is a tumour malignant?) and handwritten digits (which digit, 0–9?). For each one we will look at the data first, train the model and watch the process, and then make predictions on new, unseen samples.

ImportantWhat makes this special

No record ever leaves its hospital. Each site trains on its own patients and shares only model updates, and those updates are combined with Secure Aggregation — cryptographically masked, so not even the researcher running the training can inspect any single hospital’s contribution. Every model below is trained on the pooled population that no one was ever able to pool.

1. Connect

Log in to the three hospitals and load the three tables we will use. Then open the federated channel (a local Flower SuperLink that the hospitals connect to).

library(DSI); library(DSOpal); library(dsBaseClient); library(dsFlowerClient)
builder <- DSI::newDSLoginBuilder()
for (h in c("nairobi", "dakar", "douala")) {
  builder$append(server = h, url = paste0("https://", h, ".datashield.live"),
                 user = "ethiopia", password = "P@ssw0rd")
}
conns <- DSI::datashield.login(logins = builder$build())

DSI::datashield.assign.table(conns, "D",  "dsflower_demo.breast_cancer")  # tumours (binary)
DSI::datashield.assign.table(conns, "G",  "dsflower_demo.digits")          # digits 0-9
DSI::datashield.assign.table(conns, "G4", "dsflower_demo.digits4")         # digits 0-3
ds.flower.link.up(conns)
Note

The SuperLink runs locally on your machine; it is shut down again in the last section.

NoteA note on XGBoost here

Under Secure Aggregation each tree is a shallow stump trained from a securely-aggregated gradient histogram, and every class needs its own trees — powerful, but heavy over the secure channel, which is why we restricted it to four classes. Even so it classifies the held-out samples well. With more rounds (and a faster channel than the one we use to reach across NAT) it scales to all ten classes like any boosted model.
